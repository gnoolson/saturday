<h1 id="main">Панель</h1> 

Панель — це користувацька HTML-сторінка, призначена для введення та виведення інформації зі Сценарію.

Для запитів до Сценарію необхідно використовувати бібліотеку dashboard.js.

Ви можете підключати додаткові бібліотеки, які потрібні для зовнішнього вигляду або функціональності.
Каталог для зберігання статичних файлів визначається параметром `gnoolson.saturday.dashboard.static` у **Конфігурації Saturday**.
Статичні файли доступні за шляхом в HTML `/dashboard/static/`.


---



<h1 id="dashboard_js">dashboard.js</h1>

JS бібліотека `dashboard.js` потрібна для відправлення та отримання даних від Сценарію.

Бібліотека використовує метод Long Polling отримання вхідних повідомлень,
тому немає потреби постійно опитувати Сценарій на предмет наявності нових повідомлень.

Для підключення в HTML використайте: `import dashboard from "/dashboard/static/js/dashboard.js"`.
Перед початком роботи потрібно викликати функцію `setup(dashboardId, openDashboardId, onMessageCallback [,errorCallback])`.

```js
const dashboardId = window.dashboardId;
const openDashboardId = window.openDashboardId;
const onMessageCallback = (message)=> {};

dashboard.setup(dashboardId, openDashboardId, onMessageCallback);
```

Повідомлення від Сценарію передаються до `onMessageCallback`.  
Для надсилання повідомлення до Сценарію треба використовувати функцію `execute(message, [, successCallback, errorCallback])`. Повідомлення має бути об'єктом з довільними даними.

```js
dashboard.execute({ key : "value" });
```

Для отримання та надсилання повідомлень у Сценарії, треба використовувати інжектований сервіс [Dashboard](/docs/lua_modules#dashboard).

<h1 id="fields">Поля</h1>




<h3  id="project">Проєкт</h3>

Проєкт, до якого буде належати ця Панель. Обов’язкове поле.

---



<h3 id="name">Назва</h3>

Унікальна назва Панелі в Проєкті. Максимум 64 символи. Обов’язкове поле.

---



<h4 id="description">Опис</h4>

Текстовий опис Панелі. Максимум 5000 символів. Необов’язкове поле.

---



<h3 id="script-handler">Сценарій</h3>

Обраний Сценарій буде обробляти запити з Панелі та повертати відповіді. Обов’язкове поле.

---



<h3 id="access">Доступ</h3>

Доступ до Панелі. Обов’язкове поле.
- **Редактор** - тільки користувачі групи **Редактор** мають доступ до Панелі;
- **Глядач** - користувачі групи **Глядач** та **Редактор** мають доступ до Панелі;
- **Анонім** - доступ до Панелі не потребує авторизації.

---

Користувацька HTML-сторінка. Максимум 50 000 символів.
