<h3 id="execute"># Виконання Сценарію (Dev)</h3>

У режимі **Dev** ви можете протестувати роботу Сценарію, запустивши його вручну.  
Вхідні дані для `Args`, `Client` і `Dashboard` задаються у форматі JSON.  
Робота `Dashboard.sendMessage()` відображається у **Output**.
Помилки також відображаються у **Output**.
