<h3 id="interpreter">Інтерпретатор</h3>

У **Saturday** використовується інтерпретатор **Luaj**.
**Luaj** має деякі синтаксичні особливості. Наприклад, зарезервовані слова не можна використовувати як імена полів таблиці.

За замовчуванням стандартні бібліотеки `os` та `io` недоступні. Щоб дозволити їх використання, встановіть значення `true` для параметра `gnoolson.saturday.script.lua.full_access` у **Конфігурації Saturday**.
