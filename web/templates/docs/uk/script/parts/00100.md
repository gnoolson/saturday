<h3 id="troubleshooting">Усунення несправностей</h3>

Якщо під час виконання Сценарію виникає помилка на кшталт:
```
ClassCastException: org.luaj.vm2.Lua*** cannot be cast to gnoolson.saturday.***
```
то, найімовірніше, функція була викликана через оператор `.` замість `:`.

Дивиться журнал `application.log`. Якщо необхідно, увімкніть режим `Debug` в файлі `config/log4j2.xml`.

```
<Logger name= "gnoolson.saturday" level="debug" additivity="false">
    <AppenderRef ref="stdout"/>
    <AppenderRef ref="file"/>
</Logger>
```
