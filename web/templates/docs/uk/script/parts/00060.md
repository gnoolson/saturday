<h3 id="error">Помилки</h3>

Якщо під час виконання Сценарію виникають необроблені помилки, вони збільшують лічильник помилок.
Якщо кількість помилок перевищить допустиме значення, Сценарій буде автоматично вимкнений і заблокований.
Для розблокування необхідно усунути всі помилки.

Максимальна кількість помилок визначається параметром `gnoolson.saturday.script.max_errors` у **Конфігурації Saturday**.
