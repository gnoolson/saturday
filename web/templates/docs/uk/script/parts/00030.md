<h3 id="lifecycle">Життєвий цикл</h3>

Для кожного Сценарію створюється окремий Sandbox із власним ізольованим середовищем виконання.
Після завершення роботи Сценарію Sandbox може бути видалений або збережений у кеші для повторного використання.
Кешування дозволяє повторно використовувати вже підготовлене середовище виконання (пришвидшення роботи) та зберігати значення глобальних змінних між запусками Сценарію.

Сценарій повинен виконуватися швидко. Довгі цикли не допускаються.
Якщо час виконання перевищить значення, визначене параметром `gnoolson.saturday.script.lua.max_execution_time` у **Конфігурації Saturday**, Сценарій буде автоматично завершено.
