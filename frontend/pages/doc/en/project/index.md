<h1 id="main">Project</h1>

A project is the main organizational unit. It groups together logical components such as dashboards, scripts, schedules, and clients.

Every script, dashboard, client, and schedule must belong to a specific project.

A project can be exported and imported to back up or migrate its contents.

---

<h1 id="fields">Fields</h1>



<h3 id="name">Name</h3>

A unique project name. Maximum 64 characters. Required field.

---



<h3 id="description">Description</h3>

A text description of the project. Maximum 5000 characters. Optional field.

---
