<h1 id="main">Резервне копіювання БД</h1>

**Saturday** використовує СКБД **H2** для зберігання внутрішніх даних (проєктів, сценаріїв тощо). Для підвищення надійності рекомендується робити резервне копіювання БД.

Налаштувати параметри резервного копіювання бази даних можна у файлі **Конфігурації Saturday**.

```properties
# увімкнути резервне копіювання
gnoolson.saturday.h2.backup.use=true           

# розклад (CRON-вираз)
gnoolson.saturday.h2.backup.cron=0 0 0 * * *     

# каталог для зберігання резервних копій
gnoolson.saturday.h2.backup.path=file:data/backup   

# максимальна кількість збережених копій
gnoolson.saturday.h2.backup.max_files=3             
```
